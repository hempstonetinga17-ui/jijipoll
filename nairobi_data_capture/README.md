# Nairobi Retail Data Capture App

A React Native MVP for field data collectors to capture retail business data points in Nairobi. Built using React Native (Expo) and Firebase.

## Setup Instructions

### 1. Firebase Configuration

1. Create a Firebase project at [console.firebase.google.com](https://console.firebase.google.com).
2. Enable **Authentication** (Phone Number provider).
3. Enable **Firestore Database** and apply the rules from `firestore.rules`.
4. Add a Web App to your Firebase project and copy the configuration object.
5. Paste the configuration into `src/firebase.ts`.

### 2. Cloudflare R2 Configuration

The app uploads photos directly to Cloudflare R2 using pre-signed URLs generated by Firebase Cloud Functions.

1. Create an R2 bucket (e.g., `nairobi-data-capture`).
2. Generate an API token with read/write permissions for the bucket.
3. Configure the Cloud Functions with your R2 credentials. You can set these environment variables or use Firebase Secret Manager:
   - `R2_ENDPOINT` (e.g., `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`)
   - `R2_ACCESS_KEY_ID`
   - `R2_SECRET_ACCESS_KEY`
   - `R2_BUCKET_NAME`

### 3. Africa's Talking API

Airtime rewards are triggered via Africa's Talking.

1. Create an account at [africastalking.com](https://africastalking.com).
2. Get your `username` and `apiKey`.
3. Integrate the credentials into `functions/index.js` (uncomment the AT SDK implementation and pass the keys).

## Running the App

```bash
# Install dependencies
npm install

# Start the Expo development server
npm start
```

## Deploying Cloud Functions

```bash
cd functions
npm install
npm run deploy
```
